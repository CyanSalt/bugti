**We all write code. What's your type?**

BUGTI is a programmer personality test about the trade-offs behind your coding decisions. It explores coding preferences and offers a starting point for self-reflection and conversations with other programmers.

## Visit online

☞ https://bugti-test.vercel.app/

## Four dimensions

- **Control / Delegation (C/D):** Direct control over key mechanisms or reliance on trusted tools.
- **Flexibility / Guarantees (F/G):** Room to adapt or rules that prevent invalid states.
- **Reasoning / Experimentation (R/E):** Models and deduction or trials and observations.
- **Utility / Aesthetics (U/A):** Practical returns or the intrinsic quality of code and design.

These preferences combine into 16 personality types, grouped as Planners, Practitioners, Pioneers, and Guardians. Each type describes a different approach to programming.
