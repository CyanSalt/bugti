# BUGTI

**We all write code. What's your type?**

BUGTI is a programmer personality test about the trade-offs behind your coding decisions. It explores preferences rather than technical ability, and does not assign a personality type based on your favorite language or tool.

## Four dimensions

- **Control / Delegation (C/D):** Do you prefer direct control over key mechanisms, or entrust them to reliable tools?
- **Flexibility / Guarantees (F/G):** Do you prioritize room to adapt, or rules that prevent invalid states upfront?
- **Reasoning / Experimentation (R/E):** Do you start with a model and deduction, or prototypes, measurements, and observations?
- **Utility / Aesthetics (U/A):** Do you prioritize practical returns, or invest in the intrinsic quality of code and design?

Both sides of each dimension represent reasonable choices. Your preferences may vary with the project, team, and experience.

## Four personality groups

- **CR · Planners:** Keep control and start by reasoning through principles and structure.
- **CE · Practitioners:** Keep control and learn through hands-on trials and feedback.
- **DF · Pioneers:** Use existing capabilities and keep the route flexible.
- **DG · Guardians:** Use mature tools and clear rules to keep things working reliably.

Each group includes four types. Control types are grouped by Reasoning/Experimentation; Delegation types by Flexibility/Guarantees. The full four-letter code order stays the same.

## Using BUGTI

Explore the four dimensions on the home page, or open **Personality types** to compare all sixteen characters. On desktop, select a type from the grouped list to read its profile in the adjacent panel. On mobile, expand a type in place. Classification details are available on demand. Use the language menu to switch between Simplified Chinese and English, and the theme button to choose light or dark mode.

## Current availability

The website foundation is ready, including the home page, dimension explanations, sixteen personality introductions, and an About page. **The questionnaire is not open yet.** The test entry explains this status, and the results page does not display fabricated scores or personality reports.

There is no public deployment or sign-in system at present.

## How to interpret the test

BUGTI is intended for self-reflection and fun conversations. It is not a scientifically validated psychological assessment; the independence of its dimensions has not been statistically validated.

Do not use it to assess technical ability, screen job applicants, or decide someone's career path.
